# 🕰️ Life Easy - Productivity & Standby Dashboard

Life Easy is a fullscreen, immersive landscape dashboard for Android. Inspired by iOS Standby mode, it transforms your device into a beautiful, glanceable productivity hub perfect for desk setups and nightstands.

## ✨ Features
*   **Advanced Standby Mode:** A dual-pane landscape UI featuring a sleek digital clock and an interactive Pomodoro focus timer.
*   **OLED Burn-in Protection:** Built-in pixel-shifting algorithm that silently moves the UI to protect your screen.
*   **Premium Themes:** Deep system integrations with 4 aesthetic themes (`Void`, `Aurora`, `Sunset`, `Forest`).
*   **Smart Task & Money Manager:** Track high-priority tasks and lent/borrowed money locally on your device.
*   **System Notifications:** Fully integrated with the Android notification tray for alarms and task reminders.
*   **100% Offline & Private:** Zero cloud servers. All data is saved strictly to local device storage.

## 📥 Download & Install
You do not need to build this from source to use it. 
1. Go to the https://github.com/Panterahat/LifeEasy/releases/tag/v1 
2. Download the latest `LifeEasy.apk` file.
3. Open the file on your Android device and tap **Install** (If prompted, allow installations from "Unknown Sources").

*   **Frontend UI:** Native HTML5, CSS3, and Vanilla JavaScript.
*   **Wrapper:** Android WebView via Kotlin/Java.
*   **Architecture:** Modular, single-page application (SPA) design with DOM manipulation.
